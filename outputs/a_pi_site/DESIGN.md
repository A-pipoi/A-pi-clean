# A-pi 双主题视觉系统

## 已确认的方向

本次是现有工作台的视觉改版，不改变产品功能、文案事实、数据来源、认证、门禁或交易流程。页面模式为 Operate：可扫描性、数字辨识、稳定布局优先。

- 浅色：柔白 `#f5f6f8` 内容背景、近黑纵向导航、与内容同色的内凹选中槽。重点摘要采用薄荷绿→浅蓝→淡紫渐变。
- 深色：午夜蓝 `#080e1c` 背景、深灰蓝普通卡片、稍亮的右侧辅助区域；组合净值使用薄荷青绿→浅黄绿，配深色文字。不得改成明亮钢蓝背景或简单反色。
- 材质：轻微半透明、内高光、柔和阴影用于顶栏、菜单、弹窗和摘要；高密度表格与配置区保持稳定清晰。不能全站发光或强模糊。
- 导航槽上、下肩使用同半径的反向四分之一圆，填充与主背景一致，不描边、不叠加浮动胶囊。
- 字体沿用本地微软雅黑体系，数字使用 tabular-nums，不引入网络字体。主要容器圆角 24px，小容器 12px；间距沿用既有共享令牌。
- 独立发布副本使用新建的几何 SVG 标记，不携带第三方角色素材；启动、登录、侧栏、网站图标的用途和位置保持。原工作台素材不变。
- 分析默认紫色/辅助青色；红绿涨跌语义与风险状态仍以原业务规则为准，不能用装饰色掩盖异常。
- 反馈约 180ms，尊重 reduced-motion 与 reduced-transparency；既有主题记忆、系统偏好、跨标签页同步和图表刷新保持。

## 实施入口

`dist/design-tokens.css` 是主题令牌；`dist/reference-theme.css` 为最后加载的统一视觉层。生产通过 `scripts/build.mjs` 发布内容寻址资源，不直接上线散装源码。
