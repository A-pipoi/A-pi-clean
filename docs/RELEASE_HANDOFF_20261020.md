## 验收包用法

将源码ZIP、REPAIR_MANIFEST_20261020.json、只读verify_source_archive.py和验收文档放在同一目录。用自己可信安装的Python运行：

```powershell
python .\verify_source_archive.py .\A-pi-private-source-fixed-20261020.zip .\REPAIR_MANIFEST_20261020.json
```

应返回integrity_verified=true，installer_tested=false。清单与ZIP必须来自可信渠道；攻击者同时修改两者仍可伪造完整性，SHA256清单不是数字签名。校验不通过时不要安装，也不要粘贴来历不明的控制台命令。

正式验收必须使用之后经审核的实际安装包，另记其SHA256、提交、运行时版本与测试电脑身份。当前包不携带行情库、账号、Token、私钥、训练依赖或模型；无真实数据时保持不可用/未验收状态。
