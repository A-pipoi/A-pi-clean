# 干净Windows安装验收

状态：待执行。当前机器的虚拟环境、模拟HTTP测试和wheel安装均不等同于全新Windows验收。此文是执行清单，不是验收记录。

## 前提

1. 使用新Windows虚拟机或真实新电脑，先拍摄系统版本与安装前目录记录；不安装或运行生产副本。
2. 仅传入经审核的源码包/后续安装包和必要的依赖安装文件；不复制行情库、账号、Token、证书私钥、模型或研究记录。
3. 项目Python后端与Python 3.12 CPU训练环境分开安装。当前独立验证覆盖Python 3.14后端类型检查及Python 3.12训练；其他Python版本不能据此视为已验收。
4. 无需真实模型或行情凭据即可验收启动与无数据状态；真实接口验收另行授权。

## 操作与证据

| 项目 | 必须通过 | 保存的证据 |
|---|---|---|
| 安装路径 | 带空格、中文用户名及默认目录均可用；失败需明确报错 | 路径与安装日志，日志不得含密码 |
| 运行依赖 | 不依赖开发机Codex缓存、绝对用户路径、原工作台目录 | 解释器版本、依赖清单、进程路径 |
| HTTPS | 仅监听回环；每台安装生成独立证书，不携带发布者私钥 | 监听地址、证书指纹与有效期 |
| 首次账户 | 无通用默认密码；交互创建独立账户后能登录 | 脱敏操作记录，禁止保存密码/恢复码截图 |
| 空数据状态 | 无行情/模型凭据时展示缺失原因，不造数据、不自动请求受保护资料 | 页面截图及脱敏日志 |
| 桌面启动 | Python健康检查成功后展示页面；服务失败有可定位日志 | 首次启动、第二次启动记录 |
| 中文与主题 | 浅/深主题可读；导航、提示、长文本与通知操作可用 | 真实界面截图，不能用静态样图代替 |
| 退出与重启 | 无孤儿进程、端口占用或账户损坏；重开状态正确 | 退出前后进程/端口记录 |
| 数据隔离 | 正式与研究账户隔离，旧版本不自动继承新版本验收 | 测试账户与门禁记录 |
| 卸载 | 保留/删除用户资料选择明确，不删除项目外数据 | 卸载路径及残留核对 |

证据中的日期、版本、提交哈希、测试电脑身份与测试人员必须填写。发现失败不得直接勾选通过；修复后使用新版本重复失败项及关联回归。
